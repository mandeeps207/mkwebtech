## Launches need boring confidence

Plugin launches go better when compatibility, rollback, security, documentation, and support flows are checked before marketing starts.

```bash
wp plugin activate mk-plugin --network
wp cron event run --due-now
```

## What we verify

We test PHP versions, WordPress versions, multisite behavior, uninstall cleanup, and common hosting cache layers.
