## Install from WordPress.org

Both current MK WebTech WordPress plugins are available free from the official directory. In WordPress admin, open **Plugins -> Add New**, search for the exact plugin name, choose **Install Now**, and then activate it.

## MkWebTech CTA Studio

After activation, go to **CTAs -> Add New**. Choose Inline, Sticky Bar, Popup, or Floating Buttons, then configure the content, design, visibility, animation, placement, and optional countdown timer.

Review the [CTA Studio product documentation](/products/mkwebtech-cta-studio#installation) for the supported setup sequence and WordPress.org support link.

## Variation Swatches for WooCommerce

Install and activate WooCommerce first. Then install **MKWebTech Variation Swatches for WooCommerce**, create or edit a global product attribute, choose an MK Color, MK Dual Color, or MK Image attribute type, and configure its terms.

Review the [Variation Swatches installation guide](/products/mkwebtech-variation-swatches-for-woocommerce#installation) for the current verified workflow.

## Updates and support

Updates for these free plugins are delivered through the standard WordPress.org update flow. Use each plugin's WordPress.org support forum or the [MK WebTech contact page](/contact) for help.
