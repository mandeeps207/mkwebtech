## Before setup

Fixify's currently verified public scope is controlled shipping-address correction for eligible orders in Shopify Customer Accounts. Eligibility depends on the order state and merchant settings.

Review the [Fixify product page](/fixify) before onboarding. It documents the verified shipping-address workflow, editing-window controls, eligibility limits, current availability path, and privacy policy.

## Current access path

The repository does not contain a verified public Shopify App Store installation URL, so this guide does not invent an installation sequence. Use the [Fixify enquiry form](/contact?product=fixify) to ask about availability and onboarding for your store.

## Information to include

When contacting support, include your Shopify store domain and describe the shipping-address workflow you want to support. Do not send customer passwords, access tokens, payment details, or unnecessary customer and order data.
