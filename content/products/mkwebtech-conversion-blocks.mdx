## Overview

MKWebTech Conversion Blocks adds five conversion-focused blocks to the native WordPress editor: Countdown Timer, Sticky Notification Bar, Promo Banner, Coupon or Offer Box, and Floating CTA.

Use the blocks individually or start with one of 31 ready-made patterns for sales, launches, product promotions, seasonal campaigns, coupon offers, and other engagement workflows. WooCommerce is optional and adds store-aware display targeting when active.

## Usage

Open a post, page, or supported site-editor area, add a block from the MKWebTech category, then configure its content, visual template, responsive behavior, and display rules. Review sticky and floating placements with the active theme before publishing because fixed headers and other overlays vary between sites.
