## Overview

MKWebTech Variation Swatches for WooCommerce turns supported product variation dropdowns into clean visual controls for color, dual-color, and image attributes.

The plugin is designed for stores that want a lightweight swatch experience without replacing WooCommerce variation behavior. It keeps native select elements available for WooCommerce compatibility while adding accessible buttons for shoppers.

## Usage

Create or edit a global product attribute, choose a supported MK attribute type, configure the terms, then use that attribute for product variations.

Store-wide display controls are available under WooCommerce -> MK Swatches.
