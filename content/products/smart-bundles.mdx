## Overview

Smart Bundles helps Shopify merchants build high-converting product bundles without custom theme work. It is designed for fast catalogs, native checkout, and clean merchandising workflows.

## Installation

Install from the Shopify App Store, approve permissions, and add the bundle block to the product template. The app syncs products automatically and keeps storefront rendering lightweight.

```ts
export const bundle = {
  type: "mix-and-match",
  minimumItems: 3,
  discount: "15%"
};
```
